# 字形连连看

一个原生 macOS 字体和替换字形查看工具。输入文字，查看字体为该文字提供的所有替换字形、上下文替换和连字，以及排版效果和所有字形。

## 需要

- macOS 12.0 或更高版本。

## 支持

- .ttf .otf .ttc .otc .woff .woff2 .dfont
- 汉语（官话、[长沙话](https://github.com/howlingFounts)、[潮州话](https://github.com/Zonz-Ly)、[闽](http://ryanwuson.github.io/rime-liur)[南](https://github.com/cathree3)话、广东话、上海话）、藏语、维吾尔语、日语、韩语、英语、德语、法语、西班牙语、意大利语、巴西葡萄牙语、俄语、越南语、泰语、阿拉伯语、印地语、马来语、高棉语、拉丁语、世界语。

## 构建

```
./build.sh
```

默认构建采用所在电脑的架构。可透过标志指定架构，也可建立 ZIP 文件：

```
./build.sh -a       # arm64
./build.sh -x       # x86_64
./build.sh -u       # Universal (arm64 + x86_64)
./build.sh -z       # Current architecture + ZIP
./build.sh -u -z    # Universal + ZIP
```

## 开启

- 如果 app 被系统拦住打不开，就打开系统自带的终端 app，把 `If Won't Open Drag this into Terminal.command` 拖进去，按 `⏎`，就可以打开了。
- 在系统设置 → 一般 → 语言与地区，找到下方的应用程序，点加号，选择 Glyph Atlas，即可设置语言。

## 使用

- 在菜单栏选择「打开…」 或按 `⌘O`，可以快速在字体安装文件夹中打开字体，也可以把字体拖到 app 图标或已开启的字体窗口上来打开字体，更欢迎把本 app 设置为默认打开方式。支持最近开启的项目。
- 在菜单栏选择「拷贝到字体册」，可以把当前窗口的字体拷贝到用户字体文件夹。按住 `⌥` 后还可以选择拷贝到所有用户的字体文件夹。
- 打开可变字体时，在红绿灯旁边会有一个可变参数设置面板，还可以拖出来固定。选中数字后还可以按 `↑`／`↓` 和 `⇧↑`／`⇧↓` 调整数值。
- 在侧边栏中输入单个或多个字符来查看所有关联字形，可以用 `⌥⏎` 换行。点右键找到「常用文本」记住或快速输入文字，也可以在菜单栏中按住 `⌥` 来快速删除。还可以使用 `⇥` 和 `⇧⇥` 快速切换之前记住的文字。
- 按两下字形或选中后按 `⏎`，可以取代默认字形，并显示该字形的替换字。如果同时按住 `⇧` 就是添加这个字了
- 使用方向键 `↑`／`↓` 选择上下字形，使用 `⌥↑`／`⌥↓` 选择上下默认字形，使用 `⌘↑`／`⌘↓` 选择字形列表中的第一个和最后一个字形。
- 老鼠在 Unicode 上静置时显示该 Unicode 标准规定的字符名称。使用 `⌘C` 复制选中字形的所有编码字符。
- 可以点右键切换或使用 `⌘1` 单字形、`⌘2` 多字符、`⌘3` 字形表。可以使用 `⌃⌘S` 显示和隐藏侧边栏。
- 使用 `⌃⌘G` 开关导览。导览开启后，在多字符和字形表中点两下字形，会切换到单字形显示该字形，可以用 `⌘]`／`⌘[` 来前进和后退，也可以使用后退按钮，点右键或长按后退按钮会显示历史。
- 在多字符中点一下字形就能查看替换字。支持竖排，点右键或使用 `⌘5` 切换，文本对齐和字体排印也在这里。菜单栏「显示」中还有更多选项。
- 在字形表中点两下字形可以添加到已有文字中，在侧边栏中点一下字形还会在字形表中闪一闪。点右键可以找到「筛选特性」。
- 用 `⌘+`／`⌘−` 来放大和缩小文字，也可以使用触控板撑捏。在多字符中还可以用 `⌥⌘+`／`⌥⌘−` 或横着撑捏触控板来放大和缩小边距、用 `⌃⌘+`／`⌃⌘−` 或竖着撑捏触控板来增加和减少行距。按 `⌘0` 恢复默认大小。
- 用阴影表示边界框，包括字形宽度高度和排版行高行距，可以用 `⌘4` 隐藏。
- 有做暗黑模式，但要小心点到实心字形会眼瞎瞎喔。在菜单栏的「颜色」里可以改字形、边界框阴影和背景的颜色。调好的颜色可以点「保存当前配色」，按住 `⌥` 可以删除配色。
- 在菜单栏点「用作默认」，可以记住目前的视图、颜色、大小等预览设置和窗口大小，以后每次都以当前选择来开启字体文件。按住 `⌥` 可以改点「恢复默认」。

## 限制

- 侧边栏和全字筛选用的是自主研发的 `GSUB` 和 `AAT` 解析器，结果可能和 CoreText 整理过的不完全一致，但和字体内部一致。
- 字形名称由自主研发的解析器直接读取字体的 `post` 和 `CFF` 表，没有可读取时显示 GID。CID-keyed CFF 字体显示实际 CID。
- 字宽数据来自 CoreText 水平 advance。
- 字高数据有 `vmtx` 时来自 CoreText 垂直 advance，无则使用 `sTypoAscender + abs(sTypoDescender)`，再无及多字符使用 CoreText `ascent + descent`。
- 多字符排版及其度量由系统 TextView 提供，不可控但反映 macOS 真实效果。因无法指定不 fallback，缺字只能在结果中剔除。
- 触控板撑捏手势可能会卡住，这不是本 app 的 bug，而是 macOS 古已有之，只能祈祷林檎修复。
