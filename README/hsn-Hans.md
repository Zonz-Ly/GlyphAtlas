- 在菜单栏选「打开…」或者按 `⌘O`，就可以直接去装字体的文件夹里头开字体。也可以把字体拖到 App 图标上，或者拖到已经开过著的字体的窗口上。还可以把 Glyph Atlas 设成平常打开字体文件用的 App。前一向子开过的字体也寻得到。
- 在菜单栏可以把如今箇只窗口里头的字体拷贝到自个的字体文件夹。按住 `⌥`，就改拷贝到大家共用的字体文件夹。
- 开可变字体的时候，红绿灯边上会出来一只调参数的面板。把面板拖出来，就可以一直留到外头用。选中数值以后，按 `↑`／`↓` 和 `⇧↑`／`⇧↓` 来调。
- 在侧边栏里头打一只或者几只字，就看得到相关的字形。按 `⌥⏎` 可以换行。点右键选「常用文字」，可以存下当前文字或快速输入之前记住的文字。想倾掉存过的文字，在菜单栏按住 `⌥` 就了难著。还可以用 `⇥` 和 `⇧⇥` 快速换之前存过的文字。
- 在字形上点两下，或者选中以后按 `⏎`，就会换掉默认字形，还会列出箇只字形的替换字。想把字形加进去，就同时按住 `⇧`。
- 按 `↑`／`↓` 在字形里头上下选，按 `⌥↑`／`⌥↓` 在基本字形之间跳，按 `⌘↑`／`⌘↓` 就到列表头一只或者最后一只。
- 老鼠指针停在Unicode徽章上，就看得到Unicode标准里头定的字符名。按 `⌘C`，就把选中的字形对应的Unicode字符咸拷贝下来。
- 点右键换视图，或者按 `⌘1` 看单字形、按 `⌘2` 看多字符、按 `⌘3` 看字形表。按 `⌃⌘S` 可以显示侧边栏或者把侧边栏弆起。
- 按 `⌃⌘G` 开关导览。导览打开以后，在多字符和字形表里头点两下字形，就会跳到箇只字形的单字形。用 `⌘]`／`⌘[` 可以往前头和回去，也可以点回去按钮。在回去按钮上点右键或者按住不放，就会显示历史记录。
- 在多字符里头点一下字形，就看得到替换字。点右键或者按 `⌘5`，可以在横排和竖排之间换。文字对齐和字体排印也在右键菜单里头。菜单栏的「显示」里头还有别的选项。
- 在字形表里头点两下字形，就可以把它加到原先的文字里头。在侧边栏点一下字形，它就会在字形表里头闪一下。点右键就寻得到「筛选特性」。
- 用 `⌘+`／`⌘−` 来放大和缩细文字，也可以在触控板上用两只手指捏拢、分开。在多字符里头，用 `⌥⌘+`／`⌥⌘−` 或者横着捏合来调边距，用 `⌃⌘+`／`⌃⌘−` 或者竖着捏合来调行距。按 `⌘0` 就回到默认大细。
- 阴影标出边界框，字形的宽高、排版的行高和行距咸看得到。按 `⌘4` 就把边界框藏起来。
- 有深色模式。点到实心字形要当心，莫把眼睛晃花著。菜单栏的「颜色」里头可以改字形、边界框阴影和背景的颜色。调好就选「存下如至今的配色」。按住 `⌥` 就看得到「删除配色」。
- 在菜单栏点「拿来套做默认」，把如至今的视图、颜色、大细、别的预览设置和窗口大细咸记下来，往后开字体就照箇套设置来。按住 `⌥` 可以改选「恢复默认」。嗷呜～～～
