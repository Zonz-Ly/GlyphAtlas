- 伫菜单栏拣「开…」抑是揤 `⌘O`，会当直接对字体文件夹开字体。嘛会当共字体拖去 App 图标，抑是已经开好字体个窗口顶悬来开字体；阁较欢迎共 Glyph Atlas 设做平常开字体文件个默认 App。近来开过个文件嘛会当阁开。

- 伫菜单栏拣「拷贝到字体册」，就会当共这阵窗口开个字体拷贝去家己个字体文件夹。揤牢 `⌥`，会当改拷贝去大家共用个字体文件夹。

- 开通变字体个时，红绿灯边仔会出现调参数个面板。阁会当共面板拖出来固定。拣好数字了后，会当揤 `↑`／`↓` 佮 `⇧↑`／`⇧↓` 来调整数值。

- 伫侧边栏输入单个抑是济个字符，就会当看着相关个字形。揤 `⌥⏎` 会当换逝。揤电鼠正键拣「常用文字」，会当共这阵个文字囥起来，嘛会当较紧输入顶改囥过个文字。嘛会当伫菜单栏内底揤牢 `⌥` 来紧速刣掉。阁会当用 `⇥` 佮 `⇧⇥` 较紧切换顶改囥过个文字。

- 伫字形顶悬揤两下，抑是拣好了后揤 `⏎`，就会当共默认字形换掉，嘛会显示伊个替换字形。若是同时揤牢 `⇧`，就会加入这个字形。

- 揤 `↑`／`↓` 会当顶下拣字形；揤 `⌥↑`／`⌥↓` 会当跳去顶一个抑是后一个基本字形；揤 `⌘↑`／`⌘↓` 会当跳去列表头一个抑是尾一个字形。

- 电鼠停伫 Unicode 徽章顶悬，就会当看着 Unicode 标准规定个字符名。揤 `⌘C`，会当共拣着个字形对应个 Unicode 字符拢拷贝起来。

- 揤电鼠正键会当切换显示方式；嘛会当揤 `⌘1` 看单字形，揤 `⌘2` 看多字符，揤 `⌘3` 看字形表。揤 `⌃⌘S` 会当显示抑是藏起侧边栏。

- 揤 `⌃⌘G` 会当开关导览。导览开了后，伫多字符佮字形表点两下字形，就会跳去这个字形个单字形。揤 `⌘]`／`⌘[` 会当向头前佮倒转，嘛会当点倒转按钮。伫倒转按钮揤电鼠正键抑是揤牢，就会显示历史。

- 伫多字符点一下字形，就会当看着伊个替换字形。揤电鼠正键抑是揤 `⌘5`，会当切换横排佮竖排。文字对齐佮字体排印嘛伫遮。菜单栏个「显示方式」内底阁有较济选项。

- 伫字形表点两下字形，会当共字形加入原本个文字。伫侧边栏点一下字形阁会伫字形表内底烁一下。揤电鼠正键会当揣着「筛选特性」。

- 揤 `⌘+`／`⌘−` 放大佮缩细文字，嘛会当用两支手指伫触控板顶面搋开、合倚。伫多字符用 `⌥⌘+`／`⌥⌘−` 抑是拍横搋开、合倚会当调整边距；用 `⌃⌘+`／`⌃⌘−` 抑是拍直搋开、合倚会当调整逝距。揤 `⌘0` 会当恢复默认大细。

- 用乌影表示边界框，包括字形阔度悬度佮排版逝高逝距。会当用 `⌘4` 藏起。

- 有做暗色模式。毋过爱细腻，点着实心字形会目睭花花喔。伫菜单栏个「色水」内底会当改字形、边界框乌影佮背景个色水。调好个色水会当点「囥起这阵个配色」。揤牢 `⌥` 会当刣掉配色。

- 伫菜单栏点「设做默认」，会当记牢这阵个显示方式、色水、大细、其他预览设置佮窗口大细。后摆开字体文件，就会用这套设置。揤牢 `⌥` 会当改点「恢复默认」。
