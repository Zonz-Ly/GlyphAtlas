- 喺菜单栏拣「开…」或者按 `⌘O`，就可以直接喺装字体嘅文件夹入边打开字体。你亦可以拖字体去 App 图标，或者拖入已经打开咗字体嘅窗口，仲可以将 Glyph Atlas 设做打开字体文件嘅默认 App。最近打开过嘅项目都可以再开。
- 喺菜单栏拣「拷贝去字体册」，就可以将而家个窗口入边开咗嘅字体拷贝去自己嘅字体文件夹。按住 `⌥`，就可以改拣「拷贝去共用字体文件夹」。
- 开可变字体嗰阵，窗口嗰排红绿灯按钮隔篱会弹出调参数嘅面板。拖佢出嚟就可以一直开住。拣好数值之后，可以按 `↑`／`↓` 同 `⇧↑`／`⇧↓` 嚟调。
- 喺侧边栏打一个或者几个字符，就睇到所有相关字形。按 `⌥⏎` 可以换行。点右键拣「常用文字」，可以存低而家嘅文字，或者即刻入返之前存低嘅文字。想快啲删走存低嘅文字，可以喺菜单栏按住 `⌥`。仲可以用 `⇥` 同 `⇧⇥` 快速切换之前存低嘅文字。
- 喺字形上边点两下，或者拣咗再按 `⏎`，就会换走默认字形，同时显示佢嘅替换字形。做嗰阵按住 `⇧`，就会加埋呢个字形。
- 按 `↑`／`↓` 可以上下拣字形，按 `⌥↑`／`⌥↓` 就喺基本字形之间跳。按 `⌘↑`／`⌘↓` 可以跳去列表头一个或者最尾嗰个字形。
- 将鼠标指针停喺 Unicode 徽章上边，就睇到 Unicode 标准入边嗰个字符嘅名。按 `⌘C`，就可以拷贝拣咗嘅字形对应嘅所有 Unicode 字符。
- 可以点右键切换，或者按 `⌘1` 睇单字形、`⌘2` 睇多字符、`⌘3` 睇字形表。按 `⌃⌘S` 可以显示返或者收埋侧边栏。
- 按 `⌃⌘G` 可以开关导览。开咗导览之后，喺多字符或者字形表点两下字形，就会转去单字形睇嗰个字形。用 `⌘]`／`⌘[` 可以向前同返转头，亦可以点返转头按钮。喺返转头按钮点右键或者按住唔放，就会显示历史记录。
- 喺多字符点一下字形，就睇到佢嘅替换字形。点右键或者按 `⌘5`，就可以喺横排同竖排之间切换。文字对齐同字体排印都喺呢度。菜单栏嘅「显示」入边仲有其他选项。
- 喺字形表入边点两下字形，就可以加落原有嘅文字。喺侧边栏点一下字形，嗰个字形就会喺字形表度闪一闪。点右键可以搵到「照特性筛选」。
- 用 `⌘+`／`⌘−`，或者喺触控板用两只手指擘开或者合埋，就可以放大或者缩细文字。喺多字符可以用 `⌥⌘+`／`⌥⌘−`，或者喺触控板横向合埋或擘开手指嚟调边距。用 `⌃⌘+`／`⌃⌘−`，或者喺触控板竖向做同一个手势，就可以调行距。按 `⌘0` 就会返到默认大细。
- 阴影会显示边界框，睇到字形有几阔几高，同埋排版嘅行高同行距。按 `⌘4` 可以显示返或者收埋边界框。
- 有深色模式。点到实心字形嗰阵要小心，可能会掁亲眼。喺菜单栏嘅「颜色」可以改字形、边界框阴影同背景嘅颜色。调好就拣「存低而家嘅配色」。按住 `⌥` 就会见到「删走配色」。
- 喺菜单栏拣「用呢套做默认」，就可以记低而家嘅视图、颜色、大小同其他预览设置，连窗口大小都一齐记低。之后打开字体文件就会用返呢套设置。按住 `⌥` 可以改拣「用返默认值」。
