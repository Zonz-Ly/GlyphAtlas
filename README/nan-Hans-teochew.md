- 在菜单栏揤「开…」啊是揤 `⌘O`，就有变直接去字体文件夹许内底揣字体来开。汝也好把将字体拖到 App 图标，啊是拖入已经开有字体个窗口；也欢迎汝对 Glyph Atlas 设做平常睇字体个 App。有做「只摆开过个物件」个功能。

- 在菜单栏揤「拷贝落字体册」，就有变对只个窗口开在块个字体拷贝落家己个字体文件夹。揤紧 `⌥`，还好改选「拷贝分大家伙共用」。

- 啊是个字体开啰到个是好变字体，红绿灯骹头就会加出个调参数个面板，汝还好对个面板拖出来固定。好直接揤数字，也好揤 `↑`／`↓` 佮 `⇧↑`／`⇧↓` 来调。

- 在侧边栏拍落一个字啊是几个字，就有变睇着相关个字形，欲换行就揤 `⌥⏎`。揤猫鼠右键选「常用文字」，好存落佮换掉只阵个文字。在菜单栏揤紧 `⌥` 好撼掉勿个文字。还好揤 `⇥` 佮 `⇧⇥` 切换头前存过个文字。

- 在字形许顶揤两下，啊是选着字形再揤 `⏎`，就有变换掉默认字形，也会掊出只个字形个替换字。若是欲加加个字形在许后爿，揤紧 `⇧` 了再揤加两下字形啊是揤 `⏎`。

- 揤 `↑`／`↓` 好上下选字形，揤 `⌥↑`／`⌥↓` 好跳到顶一个啊是下一个基本字形。揤 `⌘↑`／`⌘↓` 好跳到清单头一个啊是上尾一个字形。

- 猫鼠停在 Unicode 徽章许顶，就有变睇着 Unicode 标准定个字符名。揤 `⌘C`，就有变对选着个字形个 Unicode 字符拢拷贝出来。

- 揤猫鼠右键好换显示方式，也好揤 `⌘1` 睇单字形、揤 `⌘2` 睇加字符、揤 `⌘3` 睇字形表。揤 `⌃⌘S` 好掊出啊是囥起侧边栏。

- 揤 `⌃⌘G` 开关导览。导览开在块个时候，在加字符佮字形表揤两下字形，就有变跳到只个字形个单字形。揤 `⌘]`／`⌘[` 好转来佮转去之早许块，揤转去按钮也是平样，猫鼠个伊揤紧啊是揤右键还好睇历史。

- 在加字符揤一下字形，就有变睇着伊个替换字。揤猫鼠右键啊是揤 `⌘5` 还有好换横排佮竖排。文字排列佮字体排印也在只块。菜单栏个「显示方式」许底还有别个选项。

- 在字形表揤两下字形，就有变掠只个字形加落对文字内爿。在侧边栏揤一下字形，伊还会在字形表𥍉下𥍉。揤猫鼠右键还好选「照特性筛选」。

- 揤 `⌘+`／`⌘−` 挺大佮龟细文字，也好用两支手指在触控板撑开、合磨。在加字符用 `⌥⌘+`／`⌥⌘−` 啊是拍横做只个手势好调边距；用 `⌃⌘+`／`⌃⌘−` 啊是拍直做好调行距。揤 `⌘0` 就转到默认大细。

- 阴影表示边界框，有变睇着字形个若阔佮若高，也有排版个行高佮行距。揤 `⌘4` 还有变囥起。

- 有深色模式。不果知关唔知预揤着实心字形，会变做星夜（青盲）。在菜单栏个「颜色」许底好改字形、边界框阴影佮背景个颜色。调好选「存落只阵个配色」，就有变存落来。揤紧 `⌥` 就好睇着「撼掉配色」。

- 在菜单栏选「物作默认」，就有变掠只阵个显示方式、颜色、大细、别个预览设置佮窗口大细拢记起来。后手开字体就照只套设置用。揤紧 `⌥` 就好改选「物转默认」。
