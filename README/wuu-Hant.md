- 辣選單列揀「開⋯」或者撳 `⌘O`，就好到字體檔案夾裏向直接開字體。拿字體拖到 App 圖示浪，或者拖到已經開好字體个視窗浪，儕好開。要常用 Glyph Atlas 開字體檔案，就設成預設 App。前頭開過个字體，也好辣「最近開過个字體」裏向尋著。
- 辣選單列揀「拷貝到字體簿」，搿個視窗開辣海个字體就會拷貝到自家个字體檔案夾裏向。撳牢 `⌥`，好改揀「拷貝到大家用个字體檔案夾」。
- 開可變字體个辰光，調參數个面板會辣紅綠燈邊頭出來。要一直開辣海，就拿面板拖出來。揀好數值，撳 `↑`／`↓` 搭 `⇧↑`／`⇧↓` 就好調。
- 辣側邊欄裏向打一個字或者幾個字，搭搿眼字有關係个字形儕會出來。撳 `⌥⏎` 好換行。點右鍵揀「常用文字」，好存好搿歇打好个文字，也好快點調出前頭存過个文字。要刪脫存過个文字，辣選單列撳牢 `⌥` 就好。也好用 `⇥` 搭 `⇧⇥` 快點換前頭存過个文字。
- 辣字形浪點兩記，或者揀好再撳 `⏎`，就好換脫預設字形，搿個字形个替換字形也會一道顯示出來。要加進搿個字形，點兩記或者撳 `⏎` 个辰光，一道撳牢 `⇧`。
- 撳 `↑`／`↓` 好上下揀字形，撳 `⌥↑`／`⌥↓` 好跳到上一個或者下一個基本字形。撳 `⌘↑`／`⌘↓` 就到清單頭一個或者末腳一個字形。
- 滑鼠指標停辣 Unicode 徽章浪向，就看得到 Unicode 標準裏向搿個字元个名字。撳 `⌘C`，就好拿揀好个字形對應个 Unicode 字元儕拷貝下來。
- 點右鍵好換看法，也好撳 `⌘1` 看單字形，撳 `⌘2` 看多字，撳 `⌘3` 看字形表。撳 `⌃⌘S` 好拿側邊欄顯示出來或者囥起來。
- 撳 `⌃⌘G` 好開關導覽。導覽開好，辣多字搭字形表裏向點兩記字形，就會轉到單字形，顯示搿個字形。用 `⌘]`／`⌘[` 好往前頭搭轉去，也好點轉去按鈕。辣轉去按鈕浪點右鍵或者撳牢，就會顯示歷史記錄。
- 辣多字裏向，點一下字形就看得到伊个替換字形。點右鍵或者撳 `⌘5`，橫排搭豎排就好換來換去。文字對齊搭字體排印也辣搿搭。選單列个「顯示方式」裏向還有別个選項。
- 辣字形表裏向，對準字形點兩記，就好拿伊加到原先个文字裏向。辣側邊欄點一下字形，伊會辣字形表裏向閃一閃。點右鍵好尋著「照特性篩選」。
- 用 `⌘+`／`⌘−`，或者辣觸控板浪向用兩根指頭分開、攏攏來，好放大搭縮小文字。辣多字裏向，用 `⌥⌘+`／`⌥⌘−` 或者橫過來做搿個手勢，好調寬調窄邊距。用 `⌃⌘+`／`⌃⌘−` 或者豎起來做搿個手勢，好調大調小行距。撳 `⌘0` 就轉到預設大小。
- 陰影標个是邊界框。字形有幾闊幾高，排版个行高搭行距，儕看得出。撳 `⌘4`，邊界框就好顯示出來或者囥起來。
- 有深色模式。點著實心个字形要當心，閃得來眼睛要瞎脫个。辣選單列个「顏色」裏向好調字形、邊界框陰影搭背景个顏色。調好點「存好搿歇个配色」就好存下來。撳牢 `⌥` 會看見「刪脫配色」。
- 要記牢搿歇个視圖、顏色、大小搭別个預覽設定，辣選單列揀「拿搿套當預設」就好，連視窗大小也一道記牢。以後再開字體檔案，就照搿套設定來。撳牢 `⌥`，好改揀「轉到本生个設定」。
