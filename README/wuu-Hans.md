- 辣菜单栏拣「开…」或者揿 `⌘O`，就好到字体文件夹里向直接开字体。拿字体拖到 App 图标浪，或者拖到已经开好字体个窗口浪，侪好开。要常用 Glyph Atlas 开字体文件，就设成默认 App。前头开过个字体，也好辣「最近开过个字体」里向寻着。
- 辣菜单栏拣「拷贝到字体册」，搿个窗口开辣海个字体就会拷贝到自家个字体文件夹里向。揿牢 `⌥`，好改拣「拷贝到大家用个字体文件夹」。
- 开可变字体个辰光，调参数个面板会辣红绿灯边头出来。要一直开辣海，就拿面板拖出来。拣好数值，揿 `↑`／`↓` 搭 `⇧↑`／`⇧↓` 就好调。
- 辣侧边栏里向打一个字或者几个字，搭搿眼字有关系个字形侪会出来。揿 `⌥⏎` 好换行。点右键拣「常用文字」，好存好搿歇打好个文字，也好快点调出前头存过个文字。要删脱存过个文字，辣菜单栏揿牢 `⌥` 就好。也好用 `⇥` 搭 `⇧⇥` 快点换前头存过个文字。
- 辣字形浪点两记，或者拣好再揿 `⏎`，就好换脱默认字形，搿个字形个替换字形也会一道显示出来。要加进搿个字形，点两记或者揿 `⏎` 个辰光，一道揿牢 `⇧`。
- 揿 `↑`／`↓` 好上下拣字形，揿 `⌥↑`／`⌥↓` 好跳到上一个或者下一个基本字形。揿 `⌘↑`／`⌘↓` 就到清单头一个或者末脚一个字形。
- 鼠标指针停辣 Unicode 徽章浪向，就看得到 Unicode 标准里向搿个字符个名字。揿 `⌘C`，就好拿拣好个字形对应个 Unicode 字符侪拷贝下来。
- 点右键好换看法，也好揿 `⌘1` 看单字形，揿 `⌘2` 看多字，揿 `⌘3` 看字形表。揿 `⌃⌘S` 好拿侧边栏显示出来或者囥起来。
- 揿 `⌃⌘G` 好开关导览。导览开好，辣多字搭字形表里向点两记字形，就会转到单字形，显示搿个字形。用 `⌘]`／`⌘[` 好往前头搭转去，也好点转去按钮。辣转去按钮浪点右键或者揿牢，就会显示历史记录。
- 辣多字里向，点一下字形就看得到伊个替换字形。点右键或者揿 `⌘5`，横排搭竖排就好换来换去。文字对齐搭字体排印也辣搿搭。菜单栏个「显示」里向还有别个选项。
- 辣字形表里向，对准字形点两记，就好拿伊加到原先个文字里向。辣侧边栏点一下字形，伊会辣字形表里向闪一闪。点右键好寻着「照特性筛选」。
- 用 `⌘+`／`⌘−`，或者辣触控板浪向用两根指头分开、拢拢来，好放大搭缩小文字。辣多字里向，用 `⌥⌘+`／`⌥⌘−` 或者横过来做搿个手势，好调宽调窄边距。用 `⌃⌘+`／`⌃⌘−` 或者竖起来做搿个手势，好调大调小行距。揿 `⌘0` 就转到默认大小。
- 阴影标个是边界框。字形有几阔几高，排版个行高搭行距，侪看得出。揿 `⌘4`，边界框就好显示出来或者囥起来。
- 有深色模式。点着实心个字形要当心，闪得来眼睛要瞎脱个。辣菜单栏个「颜色」里向好调字形、边界框阴影搭背景个颜色。调好点「存好搿歇个配色」就好存下来。揿牢 `⌥` 会看见「删脱配色」。
- 要记牢搿歇个视图、颜色、大小搭别个预览设置，辣菜单栏拣「拿搿套当默认」就好，连窗口大小也一道记牢。以后再开字体文件，就照搿套设置来。揿牢 `⌥`，好改拣「转到本生个设置」。
