- 在選單列揤「開⋯」啊是揤 `⌘O`，就有變直接去字體檔案夾許內底揣字體來開。汝也好把將字體拖到 App 圖示，啊是拖入已經開有字體个視窗；也歡迎汝對 Glyph Atlas 設做平常睇字體个 App。有做「只擺開過个物件」个功能。
- 在選單列揤「拷貝落字體簿」，就有變對只個視窗開在塊个字體拷貝落家己个字體檔案夾。揤緊 `⌥`，還好改選「拷貝分大家夥共用」。
- 啊是個字體開囉到个是好變字體，紅綠燈骹頭就會加出個調參數个面板，汝還好對个面板拖出來固定。好直接揤數字，也好揤 `↑`／`↓` 佮 `⇧↑`／`⇧↓` 來調。
- 在側邊欄拍落一個字啊是幾個字，就有變睇著相關个字形，欲換行就揤 `⌥⏎`。揤貓鼠右鍵選「常用文字」，好存落佮換掉只陣个文字。在選單列揤緊 `⌥` 好撼掉勿个文字。還好揤 `⇥` 佮 `⇧⇥` 切換頭前存過个文字。
- 在字形許頂揤兩下，啊是選著字形再揤 `⏎`，就有變換掉預設字形，也會掊出只個字形个替換字。若是欲加加個字形在許後爿，揤緊 `⇧` 了再揤加兩下字形啊是揤 `⏎`。
- 揤 `↑`／`↓` 好上下選字形，揤 `⌥↑`／`⌥↓` 好跳到頂一個啊是下一個基本字形。揤 `⌘↑`／`⌘↓` 好跳到清單頭一個啊是上尾一個字形。
- 貓鼠停在 Unicode 徽章許頂，就有變睇著 Unicode 標準定个字元名。揤 `⌘C`，就有變對選著个字形个 Unicode 字元攏拷貝出來。
- 揤貓鼠右鍵好換顯示方式，也好揤 `⌘1` 睇單字形、揤 `⌘2` 睇加字元、揤 `⌘3` 睇字形表。揤 `⌃⌘S` 好掊出啊是囥起側邊欄。
- 揤 `⌃⌘G` 開關導覽。導覽開在塊个時候，在加字元佮字形表揤兩下字形，就有變跳到只個字形个單字形。揤 `⌘]`／`⌘[` 好轉來佮轉去之早許塊，揤轉去按鈕也是平樣，貓鼠个伊揤緊啊是揤右鍵還好睇歷史。
- 在加字元揤一下字形，就有變睇著伊个替換字。揤貓鼠右鍵啊是揤 `⌘5` 還有好換橫排佮豎排。文字排列佮字體排印也在只塊。選單列个「顯示方式」許底還有別個選項。
- 在字形表揤兩下字形，就有變掠只個字形加落對文字內爿。在側邊欄揤一下字形，伊還會在字形表𥍉下𥍉。揤貓鼠右鍵還好選「照特性篩選」。
- 揤 `⌘+`／`⌘−` 挺大佮龜細文字，也好用兩支手指在觸控板撐開、合磨。在加字元用 `⌥⌘+`／`⌥⌘−` 啊是拍橫做只個手勢好調邊距；用 `⌃⌘+`／`⌃⌘−` 啊是拍直做好調行距。揤 `⌘0` 就轉到預設大細。
- 陰影表示邊界框，有變睇著字形个若闊佮若高，也有排版个行高佮行距。揤 `⌘4` 還有變囥起。
- 有深色模式。不果知關唔知預揤著實心字形，會變做星夜（青盲）。在選單列个「顏色」許底好改字形、邊界框陰影佮背景个顏色。調好選「存落只陣个配色」，就有變存落來。揤緊 `⌥` 就好睇著「撼掉配色」。
- 在選單列選「物作預設」，就有變掠只陣个顯示方式、顏色、大細、別個預覽設定佮視窗大細攏記起來。後手開字體就照只套設定用。揤緊 `⌥` 就好改選「物轉預設」。
