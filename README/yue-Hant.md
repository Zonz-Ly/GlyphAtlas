- 喺選單列揀「開⋯」或者撳 `⌘O`，就可以直接喺裝字體嘅資料夾開字體。你亦可以將字體拖去 App 圖像，或者拖入已經開咗字體嘅視窗，又或者將 Glyph Atlas 設做開字體檔案嘅預設 App。最近開過嘅項目都可以再開。
- 喺選單列揀「複製去字體簿」，就可以將而家個視窗入面開咗嘅字體複製去自己嘅字體資料夾。撳住 `⌥`，就可以改揀「複製去共用字體資料夾」。
- 開可變字體嗰陣，紅綠燈掣隔籬會彈出個調校參數嘅面板。拖佢出嚟就可以一路開住。揀好個數值之後，可以撳 `↑`／`↓` 同 `⇧↑`／`⇧↓` 嚟調校。
- 喺側邊欄打一個或者幾個字元，就睇到所有相關字形。撳 `⌥⏎` 可以換行。撳右鍵揀「常用文字」，可以儲低而家嘅文字，或者即刻入返之前儲低嘅文字。想快啲刪走儲低嘅文字，可以喺選單列撳住 `⌥`。仲可以用 `⇥` 同 `⇧⇥` 快速切換之前儲低嘅文字。
- 喺字形上面撳兩下，或者揀咗再撳 `⏎`，就會換走預設字形，同時顯示佢嘅替換字形。做嗰陣撳住 `⇧`，就會加埋呢個字形。
- 撳 `↑`／`↓` 可以上下揀字形，撳 `⌥↑`／`⌥↓` 就喺基本字形之間跳。撳 `⌘↑`／`⌘↓` 可以跳去列表頭一個或者最尾嗰個字形。
- 將滑鼠指標停喺 Unicode 徽章上面，就睇到 Unicode 標準入面嗰個字元嘅名。撳 `⌘C`，就可以複製揀咗嘅字形對應嘅所有 Unicode 字元。
- 可以撳右鍵切換，或者撳 `⌘1` 睇單字形、`⌘2` 睇多字元、`⌘3` 睇字形表。撳 `⌃⌘S` 可以顯示返或者收埋側邊欄。
- 撳 `⌃⌘G` 可以開關導覽。開咗導覽之後，喺多字元或者字形表撳兩下字形，就會轉去單字形睇嗰個字形。用 `⌘]`／`⌘[` 可以向前同返轉頭，亦可以撳返轉頭按鈕。喺返轉頭按鈕撳右鍵或者撳住唔放，就會顯示歷史記錄。
- 喺多字元撳一下字形，就睇到佢嘅替換字形。撳右鍵或者撳 `⌘5`，就可以喺橫排同豎排之間切換。文字對齊同字體排印都喺呢度。選單列嘅「顯示方式」入面仲有其他選項。
- 喺字形表入面撳兩下字形，就可以加落原有嘅文字。喺側邊欄撳一下字形，嗰個字形就會喺字形表度閃一閃。撳右鍵可以搵到「照特性篩選」。
- 用 `⌘+`／`⌘−`，或者喺觸控板用兩隻手指擘開或者合埋，就可以放大或者縮細文字。喺多字元可以用 `⌥⌘+`／`⌥⌘−`，或者喺觸控板橫向合埋或擘開手指嚟調校邊距。用 `⌃⌘+`／`⌃⌘−`，或者喺觸控板直向做同一個手勢，就可以調校行距。撳 `⌘0` 就會返到預設大細。
- 陰影會顯示邊界框，睇到字形有幾闊幾高，同埋排版嘅行高同行距。撳 `⌘4` 可以顯示返或者收埋邊界框。
- 有深色模式。撳到實心字形嗰陣要小心，可能會掁親眼。喺選單列嘅「顏色」可以改字形、邊界框陰影同背景嘅顏色。調好就揀「儲低而家嘅配色」。撳住 `⌥` 就會見到「刪走配色」。
- 喺選單列揀「用呢套做預設」，就可以記低而家嘅視圖、顏色、大小同其他預覽設定，連視窗大小都一齊記低。之後開字體檔案就會用返呢套設定。撳住 `⌥` 可以改揀「用返預設值」。
