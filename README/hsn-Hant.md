- 扗選單列選「打開⋯」或者按 `⌘O`，就可以直接去裝字軆的檔案夾裏頭開字軆。也可以把字軆拖到 App 圖示上，或者拖到已經開過著的字軆的視窗上。還可以把 Glyph Atlas 設成平常打開字軆檔案用的 App。歬一向子開過的字軆也尋得到。
- 扗選單列可以把如今箇隻視窗裏頭的字軆拷貝到自箇的字軆檔案夾。按住 `⌥`，就改拷貝到大家共用的字軆檔案夾。
- 開可變字軆的時候，紅綠燈邉上會出來一隻調參數的面板。把面板拖出來，就可以一直留到外頭用。選中數值以後，按 `↑`／`↓` 和 `⇧↑`／`⇧↓` 來調。
- 扗側邉欄裏頭打一隻或者幾隻字，就看得到相關的字形。按 `⌥⏎` 可以換行。㸃右鍵選「常用文字」，可以存下當歬文字或快速輸入之歬記住的文字。想傾掉存過的文字，扗選單列按住 `⌥` 就了難著。還可以用 `⇥` 和 `⇧⇥` 快速換之歬存過的文字。
- 扗字形上㸃兩下，或者選中以後按 `⏎`，就會換掉預設字形，還會列出箇隻字形的替換字。想把字形加進去，就同時按住 `⇧`。
- 按 `↑`／`↓` 扗字形裏頭上下選，按 `⌥↑`／`⌥↓` 扗基本字形之間跳，按 `⌘↑`／`⌘↓` 就到列表頭一隻或者最後一隻。
- 老鼠指標停扗 Unicode 徽章上，就看得到 Unicode 標準裏頭定的字元名。按 `⌘C`，就把選中的字形對應的 Unicode 字元咸拷貝下來。
- 㸃右鍵換視圖，或者按 `⌘1` 看單字形、按 `⌘2` 看多字元、按 `⌘3` 看字形表。按 `⌃⌘S` 可以顯示側邉欄或者把側邉欄弆起。
- 按 `⌃⌘G` 開關導覽。導覽打開以後，扗多字元和字形表裏頭㸃兩下字形，就會跳到箇隻字形的單字形。用 `⌘]`／`⌘[` 可以往歬頭和囘去，也可以㸃囘去按鈕。扗囘去按鈕上㸃右鍵或者按住不放，就會顯示歷史記錄。
- 扗多字元裏頭㸃一下字形，就看得到替換字。㸃右鍵或者按 `⌘5`，可以扗橫排和豎排之間換。文字排列和字軆排印也扗右鍵選單裏頭。選單列的「顯示方灋」裏頭還有別的選項。
- 扗字形表裏頭㸃兩下字形，就可以把它加到原先的文字裏頭。扗側邉欄㸃一下字形，它就會扗字形表裏頭閃一下。㸃右鍵就尋得到「篩選特性」。
- 用 `⌘+`／`⌘−` 來放大和縮細文字，也可以扗觸控板上用兩隻手指捏攏、分開。扗多字元裏頭，用 `⌥⌘+`／`⌥⌘−` 或者橫着捏合來調邉距，用 `⌃⌘+`／`⌃⌘−` 或者豎着捏合來調行距。按 `⌘0` 就囘到預設大細。
- 陰影標出邉界框，字形的寬高、排版的行高和行距咸看得到。按 `⌘4` 就把邉界框藏起來。
- 有深色模式。㸃到實心字形要當心，莫把眼睛晃花著。選單列的「顏色」裏頭可以改字形、邉界框陰影和背景的顏色。調好就選「存下如至今的配色」。按住 `⌥` 就看得到「刪除配色」。
- 扗選單列㸃「拿來套做預設」，把如至今的視圖、顏色、大細、別的預覽設定和視窗大細咸記下來，往後開字軆就照箇套設定來。按住 `⌥` 可以改選「囘復預設值」。嗷嗚～～～
