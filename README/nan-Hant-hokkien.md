- 佇選單列揀「開⋯」抑是揤 `⌘O`，會當直接對字體資料鋏仔開字體。嘛會當共字體拖去 App 圖示，抑是已經開好字體个視窗頂懸來開字體；閣較歡迎共 Glyph Atlas 設做平常開字體檔案个預設 App。近來開過个檔案嘛會當閣開。

- 佇選單列揀「拷貝到字體簿」，就會當共這馬視窗開个字體拷貝去家己个字體資料鋏仔。揤牢 `⌥`，會當改拷貝去逐家共用个字體資料鋏仔。

- 開通變字體个時，紅綠燈邊仔會出現調參數个面板。閣會當共面板拖出來固定。揀好數字了後，會當揤 `↑`／`↓` 佮 `⇧↑`／`⇧↓` 來調整數值。

- 佇邊仔欄輸入單個抑是濟個字元，就會當看著相關个字形。揤 `⌥⏎` 會當換逝。揤電鼠正鍵揀「常用文字」，會當共這馬个文字囥起來，嘛會當較緊輸入頂改囥過个文字。嘛會當佇選單列內底揤牢 `⌥` 來緊速刣掉。閣會當用 `⇥` 佮 `⇧⇥` 較緊切換頂改囥過个文字。

- 佇字形頂懸揤兩下，抑是揀好了後揤 `⏎`，就會當共預設字形換掉，嘛會顯示伊个替換字形。若是同時揤牢 `⇧`，就會加入這個字形。

- 揤 `↑`／`↓` 會當頂下揀字形；揤 `⌥↑`／`⌥↓` 會當跳去頂一個抑是後一個基本字形；揤 `⌘↑`／`⌘↓` 會當跳去清單頭一個抑是尾一個字形。

- 電鼠停佇 Unicode 徽章頂懸，就會當看著 Unicode 標準規定个字元名。揤 `⌘C`，會當共揀著个字形對應个 Unicode 字元攏拷貝起來。

- 揤電鼠正鍵會當切換顯示方式；嘛會當揤 `⌘1` 看單字形，揤 `⌘2` 看多字元，揤 `⌘3` 看字形表。揤 `⌃⌘S` 會當顯示抑是藏起邊仔欄。

- 揤 `⌃⌘G` 會當開關導覽。導覽開了後，佇多字元佮字形表點兩下字形，就會跳去這個字形个單字形。揤 `⌘]`／`⌘[` 會當向頭前佮倒轉，嘛會當點倒轉按鈕。佇倒轉按鈕揤電鼠正鍵抑是揤牢，就會顯示歷史。

- 佇多字元點一下字形，就會當看著伊个替換字形。揤電鼠正鍵抑是揤 `⌘5`，會當切換橫排佮豎排。文字對齊佮字體排印嘛佇遮。選單列个「顯示方式」內底閣有較濟選項。

- 佇字形表點兩下字形，會當共字形加入原本个文字。佇邊仔欄點一下字形閣會佇字形表內底爍一下。揤電鼠正鍵會當揣著「篩選特性」。

- 揤 `⌘+`／`⌘−` 放大佮縮細文字，嘛會當用兩支手指佇觸控板頂面搋開、合倚。佇多字元用 `⌥⌘+`／`⌥⌘−` 抑是拍橫搋開、合倚會當調整邊距；用 `⌃⌘+`／`⌃⌘−` 抑是拍直搋開、合倚會當調整逝距。揤 `⌘0` 會當回復預設大細。

- 用烏影表示邊界框，包括字形闊度懸度佮排版逝高逝距。會當用 `⌘4` 藏起。

- 有做暗色模式。毋過愛細膩，點著實心字形會目睭花花喔。佇選單列个「色水」內底會當改字形、邊界框烏影佮背景个色水。調好个色水會當點「囥起這馬个配色」。揤牢 `⌥` 會當刣掉配色。

- 佇選單列點「設做預設」，會當記牢這馬个顯示方式、色水、大細、其他預覽設定佮視窗大細。後擺開字體檔案，就會用這套設定。揤牢 `⌥` 會當改點「回復預設」。
